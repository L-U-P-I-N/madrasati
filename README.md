# مدرستي — نظام إدارة المدرسة الذكي (السيناريو الثالث · Enterprise)

نظام إدارة مدرسية بصلاحيات مخصّصة دقيقة وإشعارات فورية وسجل عمليات كامل، مبني وفق
تقرير «السيناريو الثالث (Enterprise)» وهوية «مدرستي» البصرية (الإصدار ١٫٠).

- **الخادم:** Laravel 11 + Sanctum (REST API)
- **الواجهة:** Next.js 15 (App Router) + TypeScript، عربية RTL بالكامل

---

## البنية

```
school/
├─ backend/     ← Laravel API
│  ├─ app/Support/        Modules · PermissionLevel · Role · ActivityLogger · Notifier

   ├─ src/app/(app)/me/   لوحة الطالب
   ├─ src/app/globals.css نظام التصميم (ألوان، خطوط، مسافات، مكوّنات)
   └─ src/lib/            api · auth · format · types
```

## التشغيل

### ١. الخادم

يتطلب PHP 8.2+ و Composer و MySQL 8 (أو SQLite).

```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

الـAPI يعمل على `http://localhost:8000/api`.

للتشغيل على SQLite بدل MySQL: اضبط `DB_CONNECTION=sqlite` في `.env` وأنشئ
`database/database.sqlite` فارغا قبل `migrate`.

### ٢. الواجهة

```bash
cd frontend
npm install
cp .env.local.example .env.local
npm run dev
```

الواجهة على `http://localhost:3000`.

## نظام الصلاحيات

خمسة مستويات تراكمية لكل وحدة من الوحدات الاثنتي عشرة:

| المستوى | القيمة | ما يستطيعه المستخدم |
|---|---|---|
| بدون صلاحية | 0 | القسم لا يظهر في القائمة نهائيا |
| عرض فقط | 1 | يرى البيانات — لا تعديل ولا إضافة ولا حذف |
| إضافة وعرض | 2 | يرى ويضيف — لا يعدّل ولا يحذف |
| إضافة وتعديل وعرض | 3 | يرى ويضيف ويعدّل — لا يحذف |
| صلاحية كاملة | 4 | عرض + إضافة + تعديل + حذف |

**الوحدات:** الطلاب · المعلمون · الصفوف · الجدول الأسبوعي · الحصص اليومية · الدرجات ·
دفتر المتابعة · ملاحظات الطلاب · الأخبار والأنشطة · الإشعارات · الصلاحيات · سجل العمليات.

### طبقتا الحماية

1. **الواجهة** تبني القائمة الجانبية والأزرار من `user.permissions` القادمة من `/api/me`.
   ما لا صلاحية عليه لا يُرسم أصلا.
2. **الخادم** يتحقق مرة أخرى عند كل طلب عبر `can.module:<module>,<ability>`، فمحاولة
   الوصول بالرابط المباشر أو باستدعاء الـAPI مباشرة تُرفض بـ403.

مدير المدرسة (`principal`) ومدير النظام (`super_admin`) يتجاوزان المصفوفة بصلاحية كاملة
دائما، وهما وحدهما من يصل إلى شاشة «إدارة الصلاحيات».

### عزل نطاق المعلم والطالب

الصلاحية وحدها لا تكفي — المتحكمات تقيّد النطاق أيضا:

- **المعلم** يرى ويعدّل بيانات مادته وفصوله المُسندة إليه فقط (`teaching_assignments`).
- **الطالب** لا يمر بوحدات الإدارة إطلاقا، بل بمسارات `/api/me/*` المربوطة بسجله شخصيا.

## الإشعارات الفورية

عند نشر خبر أو نشاط، ينشئ `Notifier::newsPublished()` صفّ إشعار لكل حساب نشط دفعة واحدة.
الواجهة تعرض عدّادا أحمر على أيقونة الجرس، والضغط على الإشعار يفتح الخبر كاملا ويُحدّث
العدّاد. الجرس يستطلع الخادم كل ٣٠ ثانية — وهي نقطة الاستبدال الطبيعية بـ WebSockets
(Laravel Reverb) عند الحاجة لبثّ لحظي حقيقي.

## سجل العمليات

كل عملية كتابة تمر بـ `ActivityLogger::log()` فتُسجَّل مع اسم المنفّذ ودوره والوحدة ونوع
العملية والوصف والحقول التي تغيّرت (قبل/بعد) وعنوان IP. شاشة السجل تدعم الفلترة بالقسم
ونوع العملية والفترة الزمنية.

## نظام التصميم

الرموز كلها في `frontend/src/app/globals.css`:

- **الكحلي** `#1A3C6E` للشريط الجانبي والترويسات · **الأزرق** `#2E6DA4` للثانوي والروابط
- **الذهبي** `#F0A500` مقدّس: زر الإجراء الرئيسي فقط — واحد لكل شاشة
- خط **Cairo**، شبكة مسافات ٤ بكسل، زوايا من ٤ إلى ١٢
- أيقونات بنمط **Heroicons** خطوط بوزن ١٫٥ — لا إيموجي ولا أيقونات ملوّنة
- الأرقام عربية-هندية، والتواريخ بالهجري والميلادي جنبا إلى جنب
- النبرة: رسمية دافئة بلا علامات تعجّب («تم الحفظ بنجاح» لا «تمام! تم الحفظ»)
